# 电赛材料目录

本目录用于存放基于当前 `STM32F407` 简易波形检测与显示项目整理出的大学生电子设计大赛文档材料。

## 文件说明

1. [01_cover.md](/d:/H/docs/contest_report/01_cover.md)
   报告封面模板，可直接补充学校、队员、指导教师等信息。

2. [02_abstract.md](/d:/H/docs/contest_report/02_abstract.md)
   摘要精简版，适合报告首页摘要或申报材料简介。

3. [03_full_report.md](/d:/H/docs/contest_report/03_full_report.md)
   正式报告正文，按竞赛/课程设计常见格式组织。

4. [04_test_data_template.md](/d:/H/docs/contest_report/04_test_data_template.md)
   测试记录表模板，可直接填写实测数据、截图编号和误差分析。

5. [05_ppt_outline.md](/d:/H/docs/contest_report/05_ppt_outline.md)
   答辩 PPT 提纲，适合直接扩展为演示文稿。

## 使用建议

1. 先修改封面中的学校、专业、姓名和日期。
2. 再根据你的实测结果补充测试数据表。
3. 如果答辩老师会核对源码，建议优先使用正文中的“已实现功能”描述，不要额外加入当前代码里没有落地的模块。
4. 若后续加入波形输出、电压量程调节、触摸交互等功能，可在正式报告第七章“改进方向”基础上继续扩展。
