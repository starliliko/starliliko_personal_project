# 课程设计报告材料

本目录用于存放基于当前 `STM32F407` 简易波形检测与显示项目整理出的大学生电子设计大赛文档材料。

> 本公开版本不包含姓名、学号、学校、班级、教师或联系方式等个人信息。

## 文件说明

1. [01_cover.md](01_cover.md)
   面向公开展示的项目封面，不包含个人身份字段。

2. [02_abstract.md](02_abstract.md)
   摘要精简版，适合报告首页摘要或申报材料简介。

3. [03_full_report.md](03_full_report.md)
   正式报告正文，按竞赛/课程设计常见格式组织。

4. [04_test_data_template.md](04_test_data_template.md)
   测试记录表模板，可直接填写实测数据、截图编号和误差分析。

5. [05_ppt_outline.md](05_ppt_outline.md)
   答辩 PPT 提纲，适合直接扩展为演示文稿。

6. [06_combined_report.md](06_combined_report.md)
   已脱敏的完整 Markdown 报告，适合在 GitHub 直接阅读。

## 使用建议

1. 根据实测结果补充测试数据表。
2. 对外发布前再次检查图片、导出文件和文档属性，不要加入个人身份信息。
3. 如果答辩老师会核对源码，建议优先使用正文中的“已实现功能”描述，不要额外加入当前代码里没有落地的模块。
4. 若后续加入波形输出、电压量程调节、触摸交互等功能，可在正式报告第七章“改进方向”基础上继续扩展。
