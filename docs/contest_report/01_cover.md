# 大学生电子设计大赛设计报告

## 题目

基于 STM32F407 的波形检测与显示装置

## 项目信息

- 作品类型：嵌入式测量与显示系统
- 开发平台：STM32F407ZGT6
- 开发环境：STM32CubeMX、Keil MDK、VS Code
- 软件框架：HAL、FreeRTOS、LVGL、CMSIS-DSP
- 项目状态：课程设计原型

## 公开展示说明

本版本用于 GitHub 项目展示，已省略姓名、学号、学校、班级、教师和联系方式等个人信息。

## 声明

本作品围绕输入波形的采样、分析与显示展开设计，完成了信号采集、参数测量、波形识别及液晶实时显示等功能。系统目前已实现简易示波显示的核心能力，适用于电子实验、教学演示和基础波形分析场景。
