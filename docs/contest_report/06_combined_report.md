## 摘要

本设计以 STM32F407 单片机为核心，完成了一套简易波形检测与显示装置。系统面向正弦波、方波、三角波等常见周期信号，能够对输入信号进行高速采样、频率分析、电压参数测量和波形类型识别，并通过 TFTLCD 实时显示波形及测量结果。

硬件部分利用 STM32F407 内置 12 位 ADC、定时器触发、DMA 循环搬运和 FSMC 并口液晶接口搭建数据采集与显示平台。软件部分基于 STM32CubeMX、HAL 库、FreeRTOS 和 LVGL 图形库实现多任务系统，采用“采样任务、波形处理任务、显示任务”分工运行。系统在 2 MHz 常规采样率下，对 1 kHz 至 200 kHz 范围内的周期信号具有较好的采集与显示能力。波形分析过程中，采用 FFT 频谱分析与时域特征提取相结合的方法，完成频率估计、幅值计算、均值与有效值测量以及波形分类。

测试结果表明，系统能够较稳定地实现波形采集、参数测量与界面刷新，具备较好的实时性和可视化效果。该设计验证了 STM32F407 在嵌入式测量仪器中的应用可行性，为后续扩展触摸交互、自动量程、前端调理电路和双通道完整示波功能提供了基础。

**关键词**：STM32F407；ADC；DMA；FreeRTOS；LVGL；FFT；波形识别

## 一、设计任务与总体要求

### 1.1 设计背景

在电子系统调试、实验教学和基础测量中，常常需要观察输入信号的频率、幅值及波形类型。传统台式示波器功能完善，但成本较高、体积较大，不利于在教学实验和嵌入式场景中灵活部署。基于单片机实现简易波形检测与显示装置，不仅能降低成本，还能将硬件设计、嵌入式软件开发和数字信号处理结合起来，具有较高的工程实践价值。

### 1.2 设计目标

本系统拟实现以下目标：

1. 对外部输入波形进行稳定采样；
2. 对采样数据完成频率、电压参数和波形类别分析；
3. 在液晶屏上实时显示波形曲线与测量结果；
4. 通过多任务设计提升系统实时性和模块清晰度。

### 1.3 技术指标

| 项目 | 指标要求 |
| --- | --- |
| 输入信号类型 | 正弦波、方波、三角波 |
| 输入频率范围 | 1 kHz ～ 200 kHz |
| 输入幅度范围 | 0 V ～ 3 V 峰峰值 |
| ADC 采样率 | 常规 2 MHz |
| 处理数据长度 | 1024 点 |
| 显示刷新频率 | 约 20 Hz |
| 显示内容 | 波形、频率、电压值、波形类别 |

## 二、系统总体方案

### 2.1 系统总体结构

系统由信号采集模块、数据处理模块和波形显示模块三部分组成。

1. **信号采集模块**  
   利用 STM32F407 内置 ADC 对输入模拟信号进行采样，并由定时器控制采样节奏，通过 DMA 将数据搬运到缓冲区。

2. **数据处理模块**  
   对 ADC 原始数据进行电压换算、频率分析、波形分类和参数测量，输出可供显示模块使用的结果。

3. **显示模块**  
   基于 TFTLCD 和 LVGL 图形库实现示波器风格界面，显示背景网格、波形曲线和参数表格。

### 2.2 方案选择与论证

为了兼顾实时性与可扩展性，系统采用“STM32F407 + HAL + FreeRTOS + LVGL”的整体方案。

- STM32F407 主频高，片上资源丰富，具备 ADC、DMA、FSMC 和 FPU，能够满足高速采样与实时显示需求。
- HAL 库可降低外设开发复杂度，便于维护和移植。
- FreeRTOS 可将采样、计算和显示解耦，提高系统响应能力。
- LVGL 适合构建结构清晰的图形界面，能够提升显示效果和后续扩展能力。

## 三、硬件系统设计

### 3.1 主控模块设计

主控芯片采用 STM32F407ZGT6。该芯片基于 ARM Cortex-M4 内核，主频最高 168 MHz，内置单精度浮点运算单元，适合执行 FFT 和电压参数计算等运算任务。

其主要优势如下：

1. 内置 12 位 ADC，可完成高速数据采样；
2. 支持 DMA，减轻 CPU 数据搬运负担；
3. 支持 FSMC，可高速驱动并口液晶；
4. 定时器资源丰富，适合作为 ADC 触发源。

### 3.2 信号采集部分设计

系统当前采用 STM32F407 的两个 ADC 通道进行配置，便于后续双通道扩展。实际演示和测试可针对单路输入信号进行。

由于 STM32F407 的 ADC 输入范围为 0～3.3 V，因此输入信号需满足单极性电压条件。若信号发生器输出为双极性信号，则应通过偏置电路将其抬升至 ADC 可采样范围。

### 3.3 定时器与 DMA 设计

定时器 TIM2 用于周期性触发 ADC 采样，通过调整预分频值和自动重装值实现不同采样率。DMA 配置为循环模式，可自动将 ADC 采样数据写入双缓冲区，实现采样与处理并行。

这种结构具有以下优点：

1. 采样时刻精确可控；
2. DMA 自动搬运，减少 CPU 参与；
3. 通过半传输与全传输回调，可在数据尚未采完下一缓冲区前完成上一缓冲区处理。

### 3.4 显示模块设计

显示部分使用 2.8 寸 TFTLCD，通过 FSMC 并口与 STM32F407 连接。与 SPI 接口相比，FSMC 在刷屏速度方面更具优势，适合实时绘制波形。

液晶界面主要显示以下内容：

1. 波形背景网格；
2. 采集波形曲线；
3. 测量参数表格；
4. 当前频率、电压和波形类别。

## 四、软件系统设计

### 4.1 软件架构

软件采用模块化与分层设计，主要包括：

1. **底层驱动层**：GPIO、ADC、DMA、TIM、FSMC、LCD、触摸、按键等；
2. **中间件层**：FreeRTOS、LVGL、CMSIS-DSP；
3. **应用层**：ADC 采集任务、波形处理任务、界面刷新任务。

整个软件体系建立在 STM32CubeMX 自动生成框架之上，在用户代码区完成功能扩展与任务实现。

### 4.2 任务设计

系统主要包含以下任务：

1. **ADC 采集任务**  
   优先级较高，用于等待 DMA 缓冲区填充完成后拆分双通道数据；

2. **波形处理任务**  
   对采样缓冲区中的波形执行频率估计、电压测量和波形分类；

3. **LVGL 显示任务**  
   完成图形库初始化，并周期性执行界面刷新；

4. **LED 任务**  
   用于运行状态指示和系统工作验证。

### 4.3 ADC 采样程序设计

系统采用“定时器触发 + DMA 双缓冲 + 中断通知”的结构完成数据采集。

基本流程如下：

1. 定时器 TIM2 产生固定频率触发信号；
2. ADC 在触发时刻进行转换；
3. DMA 自动将结果写入采样缓冲区；
4. 半缓冲完成和全缓冲完成时触发回调函数；
5. 回调函数通知 ADC 任务读取已填满的缓冲区。

本方案的优点在于：

1. 采样周期由硬件控制，时间精度高；
2. DMA 减少了 CPU 干预；
3. 任务与中断配合，使采集和处理流程并行化。

### 4.4 波形分析算法设计

波形分析模块主要包括以下步骤：

#### 4.4.1 数据预处理

将 ADC 原始采样值转换为对应电压值，并对波形做均值处理，以减小直流分量影响。对于 FFT 频谱分析部分，使用窗函数减小频谱泄漏。

#### 4.4.2 频率计算

采用 FFT 对 1024 点波形数据进行频谱分析，通过寻找主频峰值估计信号频率，并进一步通过抛物线插值提高频率分辨率，使结果更加平滑。

#### 4.4.3 电压参数测量

对波形数据计算以下指标：

1. 最大值；
2. 最小值；
3. 平均值；
4. 有效值；
5. 幅值；
6. 周期；
7. 占空比。

#### 4.4.4 波形类别识别

系统将频域和时域特征结合起来进行波形分类，主要依据包括：

1. 基波与谐波幅度分布；
2. 总谐波失真；
3. 波形过零点特征；
4. 斜率变化趋势；
5. 均值与有效值之间的关系。

通过这些规则，可对正弦波、方波、三角波、锯齿波和噪声类波形进行初步识别，其中本设计重点考察正弦波、方波和三角波。

#### 4.4.5 触发控制

为提高波形显示稳定性，系统支持自动触发、常态触发和单次触发，并可设置上升沿或下降沿触发。这样可在显示区内尽量固定波形起始位置，增强可读性。

### 4.5 图形显示模块设计

液晶界面采用示波器风格布局，屏幕划分为两个区域：

1. 上部为波形绘图区；
2. 下部为参数显示表格区。

显示模块的主要功能包括：

1. 绘制背景颜色、网格和坐标轴；
2. 实时绘制通道波形曲线；
3. 刷新参数表格中的频率、电压和波形类别；
4. 通过 LVGL 定时器控制刷新频率。

系统当前界面刷新周期约为 50 ms，对应刷新频率约 20 Hz，能够满足基础波形观测需求。

## 五、系统调试与测试

### 5.1 调试步骤

系统调试主要分为以下几个阶段：

1. 外设初始化验证，包括 GPIO、ADC、DMA、TIM 和 LCD；
2. 采样链路验证，检查 ADC 采样缓冲区内容是否正确；
3. FFT 和参数计算模块验证；
4. 波形分类功能验证；
5. 界面刷新与参数显示验证。

### 5.2 测试方法

测试时使用信号发生器输出不同类型的规则波形，调整频率与幅度，在保证输入电压满足 0～3.3 V 范围的前提下接入系统进行测试。

主要测试内容包括：

1. 不同频率下的波形采样稳定性；
2. 正弦波、方波、三角波的分类结果；
3. 电压参数与频率测量结果；
4. 界面显示实时性与稳定性。

### 5.3 测试结果分析

在当前实现条件下，系统能够对 1 kHz～200 kHz 范围内的周期信号进行采样和显示。对规则输入信号，系统可较稳定给出频率、电压与波形类型结果，界面刷新较流畅，满足简易示波显示装置的设计要求。

测试结果表明：

1. 基于定时器触发和 DMA 的采样机制能够保证数据连续性；
2. 1024 点 FFT 适合完成本系统的频率分析任务；
3. FreeRTOS 多任务调度提升了系统结构清晰度与并行性；
4. FSMC 驱动液晶能够支持波形实时刷新。

## 六、作品特点与创新点

### 6.1 采样与处理并行

通过 DMA 和任务机制将采样、计算与显示并行执行，提高了系统实时性，减轻了 CPU 负担。

### 6.2 时域与频域特征融合

系统并非只使用单一指标判断波形，而是结合 FFT 谱特征和时域变化规律进行分类，增强了识别能力。

### 6.3 嵌入式图形界面设计

采用 LVGL 构建示波器式界面，实现网格、波形和参数表格的统一显示，提高了系统可视化效果和演示性。

### 6.4 模块化结构便于扩展

当前工程已形成较清晰的驱动层、中间件层和应用层结构，便于后续扩展触摸调参、前端调理、自动量程和双通道完整功能。

---

## 七、不足与改进方向

### 7.1 输入适配能力有限

当前系统主要面向 0～3.3 V 单极性输入信号。若外部信号为双极性，需要额外增加偏置电路。后续可增加模拟前端电路，提高通用性。

### 7.2 抗干扰能力仍可优化

在强噪声环境下，采样结果和波形分类准确性会受到影响。后续可加入 RC 滤波、屏蔽设计以及更稳定的数字滤波算法。

### 7.3 人机交互功能仍较基础

当前界面以波形显示与参数查看为主。后续可增加触摸交互功能，如时间量程切换、电压量程切换、触发模式设置和参数保持功能。

### 7.4 前端测量能力可继续增强

若后续增加自动增益调节、电压分压保护、输入缓冲和耦合切换功能，则系统可向更完整的便携式示波器方向演进。

---

## 八、结论

本设计完成了一套基于 STM32F407 的简易波形检测与显示装置。系统能够对输入周期信号完成采样、频率分析、电压参数测量和波形识别，并在 TFTLCD 上进行实时显示。通过定时器触发 ADC、DMA 双缓冲传输、FreeRTOS 多任务调度和 LVGL 图形界面构建，系统在实时性、结构清晰度和可展示性方面均达到了预期目标。

该设计体现了嵌入式系统在信号测量仪器中的实际应用能力，也为后续向更高精度、更强交互、更完整功能的数字示波系统扩展提供了基础。

## 十、答辩 PPT 提纲

### 第 1 页：封面

- 题目：基于 STM32F407 的波形检测与显示装置
- 作品类型：嵌入式测量与显示系统
- 开发平台：STM32F407ZGT6
- 技术栈：HAL、FreeRTOS、LVGL、CMSIS-DSP

### 第 2 页：项目背景与设计目标

- 介绍波形检测在电子测量与教学中的应用场景
- 说明传统示波器成本高、便携性差
- 引出本系统的设计目标
- 给出系统要实现的核心功能

### 第 3 页：总体方案

- 展示系统框图
- 说明三大模块：信号采集模块、数据处理模块、显示模块
- 强调采用 STM32F407 作为核心控制器

### 第 4 页：硬件设计

- STM32F407 主控资源说明
- ADC 采样通道与输入条件
- TIM2 触发 ADC 的思路
- DMA 搬运采样数据
- TFTLCD 通过 FSMC 高速显示

### 第 5 页：软件架构

- CubeMX + HAL + FreeRTOS + LVGL 总体结构
- 任务划分：ADC 采集任务、波形处理任务、显示任务
- 简述多任务设计带来的好处

### 第 6 页：ADC 采样流程

- 定时器触发采样
- DMA 双缓冲区搬运
- 半传输/全传输回调通知任务
- 说明这样做可降低 CPU 占用

### 第 7 页：波形分析算法

- ADC 原始数据转电压值
- FFT 计算频率
- 计算最大值、最小值、均值、有效值
- 结合谐波和时域特征进行波形识别
- 支持触发模式稳定显示

### 第 8 页：界面显示设计

- 展示 UI 截图
- 说明画布区与参数区布局
- 说明网格、波形和参数表格的刷新方式
- 给出界面刷新周期约 50 ms

### 第 9 页：测试结果

- 放入实物图和运行截图
- 展示频率测试表
- 展示波形识别结果
- 展示不同输入条件下的显示效果

### 第 10 页：作品特点

- 采样、处理、显示并行运行
- 频域与时域特征融合识别
- 图形界面直观，便于展示
- 系统结构清晰，便于扩展

### 第 11 页：不足与改进方向

- 输入信号范围仍受 ADC 电压限制
- 抗干扰能力还有提升空间
- 触摸交互和自动量程功能仍待完善
- 后续可扩展更完整的前端调理和便携式示波器功能

### 第 12 页：总结

- 已完成波形采样、参数分析与实时显示
- 达到简易示波检测装置的预期目标
- 具有继续扩展与优化的工程价值

### 演讲建议

1. 开场先讲“问题和目标”，不要一上来讲芯片参数。
2. 测试页尽量放真实照片、真实屏幕截图和实测数据。
3. 如果老师追问“为什么不用纯裸机”，可以回答多任务结构更清晰，便于采样、计算、显示解耦。
4. 如果老师追问“为什么是 2 MHz”，可以结合 ADC 采样速率、两通道采样和显示稳定性一起解释。
5. 如果老师追问“有没有输出模块”，建议回答当前版本以检测与显示为主，输出功能作为后续扩展方向。
