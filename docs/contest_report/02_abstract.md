# 摘要

本设计以 STM32F407 单片机为核心，完成了一套简易波形检测与显示装置。系统面向正弦波、方波、三角波等常见周期信号，能够对输入信号进行高速采样、频率分析、电压参数测量和波形类型识别，并通过 TFTLCD 实时显示波形及测量结果。

硬件部分利用 STM32F407 内置 12 位 ADC、定时器触发、DMA 循环搬运和 FSMC 并口液晶接口搭建数据采集与显示平台。软件部分基于 STM32CubeMX、HAL 库、FreeRTOS 和 LVGL 图形库实现多任务系统，采用“采样任务、波形处理任务、显示任务”分工运行。系统在 2 MHz 常规采样率下，对 1 kHz 至 200 kHz 范围内的周期信号具有较好的采集与显示能力。波形分析过程中，采用 FFT 频谱分析与时域特征提取相结合的方法，完成频率估计、幅值计算、均值与有效值测量以及波形分类。

测试结果表明，系统能够较稳定地实现波形采集、参数测量与界面刷新，具备较好的实时性和可视化效果。该设计验证了 STM32F407 在嵌入式测量仪器中的应用可行性，为后续扩展触摸交互、自动量程、前端调理电路和双通道完整示波功能提供了基础。

**关键词**：STM32F407；ADC；DMA；FreeRTOS；LVGL；FFT；波形识别
